# 功能路径覆盖

> 可调用技能：分析策划案中的功能流程，提取主路径和分支路径，生成功能覆盖测试点。

## 触发条件

当策划案描述了以下内容时调用此技能：
- 明确的用户操作流程（如"玩家点击→选择→确认→完成"）
- 功能入口和出口（如"从主界面进入商店"）
- 业务场景的完整流转（如"创建角色→选择职业→进入游戏"）
- 条件分支（如"VIP 用户看到 A 界面，普通用户看到 B 界面"）

## 输入

- 策划案中描述功能流程的段落
- 涉及的用户角色或权限等级
- 功能的入口和出口描述

## 执行步骤

1. **识别功能入口**：找出所有可以触发该功能的入口（按钮、菜单、事件触发等）
2. **绘制主成功路径（Happy Path）**：从入口到最终成功结果的最短正常路径
3. **识别决策点**：找出流程中每个条件判断节点（如等级判断、VIP 判断、数量判断）
4. **展开分支路径**：每个决策点至少覆盖"满足条件"和"不满足条件"两条分支
5. **识别循环路径**：是否存在可重复执行的流程（如重复购买、多次挑战）
6. **标注中断点**：流程中可能被中断的位置（断线、切后台、超时）
7. **生成测试点**：每条独立路径生成一个测试点

## 输出规范

每条路径输出一个测试点，格式：
- `id`: TP-FP-xxx（FP = Functional Path）
- `type`: "functional"
- `title`: 路径描述（如"主成功路径：正常购买流程"）
- `priority`: P0（主路径）/ P1（分支路径）/ P2（循环和中断路径）
- `steps`: 从入口到出口的操作步骤
- `expected`: 每步的预期结果

## 质量检查

- [ ] 至少覆盖 1 条完整的主成功路径
- [ ] 每个决策点的每个分支至少有 1 个测试点
- [ ] 循环流程至少覆盖：首次执行、再次执行、达到上限
- [ ] 标注了所有中断恢复场景
