# 边界值设计

> 可调用技能：识别策划案中的数值字段和范围约束，生成边界值测试点。

## 触发条件

当策划案描述了以下内容时调用此技能：
- 数值范围（如"等级 1-100"、"价格 0.01-99999"）
- 数量限制（如"背包上限 200 个"、"每日最多领取 3 次"）
- 字符串长度约束（如"昵称 2-12 个字符"）
- 时间范围（如"活动持续 7 天"、"冷却时间 30 秒"）
- 百分比和概率（如"暴击率 0%-100%"）
- 枚举值和选项（如"品质分为白绿蓝紫橙"）

## 输入

- 策划案中涉及数值、范围、限制的段落
- 字段的数据类型（整数、浮点数、字符串、日期等）
- 明确的上下限或约束条件

## 执行步骤

1. **提取所有数值字段**：从策划案中找出每个有范围约束的字段
2. **确定边界点**：对每个字段列出关键边界值
   - 最小值、最小值-1、最小值+1
   - 最大值、最大值-1、最大值+1
   - 零值 / 空值
   - 典型值（范围中间）
3. **识别特殊值**：
   - 负数（如果类型允许）
   - 非法字符（如果是字符串字段）
   - 超长输入
   - 小数/浮点精度问题
4. **分析组合边界**：多个字段同时处于边界值时的交互
5. **生成测试点**：每个边界条件生成一个测试点

## 输出规范

每个边界条件输出一个测试点，格式：
- `id`: TP-BV-xxx（BV = Boundary Value）
- `type`: "boundary"
- `title`: 边界描述（如"购买数量为最大值 99 时的处理"）
- `priority`: P0（核心字段边界）/ P1（普通字段边界）/ P2（特殊值）
- `test_data`: 具体的测试输入值
- `expected`: 系统对该边界值的预期处理

## 质量检查

- [ ] 每个数值字段至少覆盖：最小值、最大值、零值、越界值
- [ ] 字符串字段至少覆盖：空串、最短、最长、超长、特殊字符
- [ ] 标注了哪些边界值可能导致数据溢出或精度问题
- [ ] 涉及金额/货币的字段必须测试小数精度
